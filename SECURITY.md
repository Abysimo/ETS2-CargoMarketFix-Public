# Security

Do not disclose vulnerabilities through public issues. Use GitHub private vulnerability reporting when it is available and enabled for this repository. If it is unavailable, do not post vulnerability details publicly; no alternative private contact address is designated here.

Do not include credentials, personal logs, game saves or other private information in public reports. Review and redact diagnostic attachments before sharing them.

See the README supported-version table for validated releases. Executable support is exact-build gated: do not disable safety gates or adapt patch bytes to an unvalidated executable. Close the game before changing or removing the plugin, and keep save backups before testing plugins.
