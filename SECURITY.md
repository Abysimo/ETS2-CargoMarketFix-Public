# Security

This repository is private release preparation. Do not post security reports, credentials, game saves or personal logs as public issues.

After public publication, use GitHub private vulnerability reporting if it has been enabled. No private contact address is designated here.

Only ETS2 1.57.2.7 with the exact supported executable identity is validated. Do not disable build gates or adapt patch bytes to an unvalidated executable. Close the game before changing or removing the plugin. Keep backups of saves before testing any plugin.
